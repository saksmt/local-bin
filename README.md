# @saksmt script collection

Some scripts born while using gentoo & nixos

Since some of the scripts are related to NixOS here is a [link](https://github.com/saksmt/nix-config) to my NixOS configuration

**WARN** Gentoo related scripts weren't tested for a long time!

**WARN** Scripts in this branch are no longer actively used and only develop branch targeted to NixOS is somewhat fresh

## Installation

```bash
$ PREFIX=/usr/local make install -e
```

## Deinstallation

```bash
$ PREFIX=/usr/local make uninstall -e
```

## Installation (if you have no git right now)

```bash
curl -SsL https://raw.githubusercontent.com/saksmt/local-bin/non-nix-legacy/install-no-git.sh | sh -s /usr/local
```
